# 00 · 前置准备（从买线开始）

## 1. 你需要什么

| 项 | 要求 | 说明 |
| --- | --- | --- |
| iPhone | iOS **27+** | 27 起有免签名原生控制（无障碍 + HID）。17–26 只能退回 WDA，要免费 Apple ID 每 7 天重签，本项目不走那条路 |
| 数据线 | 能传数据的 Lightning/USB-C 线 | 只能充电的线在 `system_profiler` / 设备管理器里看不到设备 |
| 主机 | **常开的** Mac（Intel/ARM 都行）或 Linux x86_64 | 手机要一直插着；Mac 用系统自带 usbmuxd，Linux 用 `usbmuxd` 包 |
| 网络 | 主机能被你的页面/服务端访问 | 本项目验证环境：Mac 与 NAS 同局域网，NAS 上跑队列与页面 |
| 账号 | **不需要** Apple ID、不需要付费开发者账号 | 全程零签名 |

> 手机上**什么都不用装**。不需要 WDA、不需要 DeviceKit、不需要描述文件、不需要信任电脑证书。

## 2. 手机侧要打开的开关

1. **设置 → 隐私与安全性 → 开发者模式 → 打开 → 重启 → 确认**。
   - 有锁屏密码时命令行开不了：`ios devmode enable` 会回 `Device has a passcode set (Developer Mode menu has been revealed in Settings)`，只能人工点。
   - 关掉它会报 `ImageMountFailed ... Code=-4 "Developer mode is not enabled."`，控制直接失效。
2. 第一次插线时手机上点「信任此电脑」。
3. 关掉「自动锁屏」或至少保证**不要按锁屏键**（本项目明确不使用 lock 键；锁屏本身不影响自动化，但会挡住我们用截图做 UI 操作）。

## 3. 主机侧要装什么

### macOS

```bash
# 命令行工具（没有 CLT 时报 xcode-select: Unable to get active developer directory）
sudo softwareupdate -l                      # 找到 "Command Line Tools for Xcode-16.2"
sudo softwareupdate -i "Command Line Tools for Xcode-16.2"
xcode-select -p                             # /Library/Developer/CommandLineTools
clang --version                             # Apple clang 17.x

# Rust
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs -o /tmp/rustup.sh
sh /tmp/rustup.sh -y --profile minimal --default-toolchain stable
~/.cargo/bin/cargo --version                 # 1.100.0 起
```

### Linux（Debian/Ubuntu）

```bash
sudo apt install -y usbmuxd libimobiledevice-utils pkg-config libssl-dev build-essential
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs -o /tmp/rustup.sh && sh /tmp/rustup.sh -y
```

Linux 上 `usbmuxd` 必须存在且在跑（`systemctl status usbmuxd`）；macOS 自带。

## 4. 三条必须记住的排他规则

1. **同一时间只能有一个 usbmuxd 客户端**：`go-ios`、`AltServer`、`pymobiledevice3` 与本项目会互相抢设备。装好本项目后先 `pkill -f "goios/ios"; pkill -f AltServer`。
2. **开发者镜像（DDI）只能挂一次**：如果之前用 go-ios 挂过，`iphone-control doctor` 会报
   `ImageMountFailed ... com.apple.MobileAsset.DDI: mkdir custom mount path: /System/Developer [17: File exists]`。
   修法：`~/goios/ios image unmount`（或重启手机），然后重启本项目的守护进程。
3. **不要用 Windows 走这条路**：`go-ios` 在 Windows 上只能读不能点（UIAutomation 需要 Apple 签名的 runner，等于又要签名）。Windows 只适合做「发指令的客户端」。

## 5. 目录与产物约定

```
~/iphone-control/          # 二进制与守护进程日志（本项目用 ~/.cargo/bin/iphone-control）
~/ic_call.py               # 单次 MCP 调用
~/ic_repeat.py             # 同一会话内重复调同一个工具 N 次
~/ic_shot_*.bin            # 截图产物（JPEG，375x667 点，像素=点）
```
