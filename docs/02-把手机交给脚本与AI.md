# 02 · 把手机交给脚本与 AI

`iphone-control mcp` 是一个 stdio 的 MCP 服务：发 `initialize`、`notifications/initialized`，然后一条条 `tools/call` 即可。用一个小脚本包起来，任何 agent / shell 都能驱动。

## 1. 两个必备脚本

### `scripts/ic_call.py` —— 单次调用

```bash
ssh mac 'python3 ~/ic_call.py iphone_tap "{\"x\":188,\"y\":562}"'
ssh mac 'python3 ~/ic_call.py iphone_list_elements "{\"limit\":60}"'
ssh mac 'python3 ~/ic_call.py iphone_screenshot "{}"'
```

遇到 `image` 类型结果时，它把 base64 落成 `~/ic_shot_<bytes>.bin` 并打印路径。

### `scripts/ic_repeat.py` —— 同一会话里重复调同一个工具

关键点：**每次 `ic_call.py` 都是新进程 = 新 MCP 会话**，做「连点 20 次删除键」这类动作会非常慢且容易断。`ic_repeat.py` 在一个会话内循环：

```bash
ssh mac 'python3 ~/ic_repeat.py iphone_tap "{\"x\":349,\"y\":593}" 45'   # 连按删除键 45 次
```

## 2. 工具参数速查（实测，别照 README 猜）

| 工具 | 参数 | 备注 |
| --- | --- | --- |
| `iphone_status` | `{}` | 控制方式 / 锁屏 / 前台 App / 屏幕点数 |
| `iphone_screenshot` | `{}` | 返回 `IMAGE saved ~/ic_shot_N.bin` |
| `iphone_list_elements` | `{"limit":N}` | 返回带文字与 `@(x,y)` 的元素树 |
| `iphone_tap` | `{"x","y"}` | 坐标单位 = 点 = 像素 |
| `iphone_tap_element` | `{"text":"..."}` | 按可见文字点，最稳 |
| `iphone_long_press` | `{"x","y"}` | 弹菜单用 |
| `iphone_swipe` | `{"from_x","from_y","to_x","to_y"}` | **不是** x1/y1/x2/y2 |
| `iphone_type_text` | `{"text":"..."}` | 支持中文；文本字段里光标总在末尾 |
| `iphone_launch_app` | `{"app":"com.apple.shortcuts"}` | **不是** bundle_id |
| `iphone_open_url` | `{"url":"..."}` | Safari 打开 |
| `iphone_press_button` | `{"button":"home"}` | **绝不要传 `lock`** |
| `iphone_batch` | 最多 20 步 | 存在且可用 |

## 3. 坐标铁律（省下几小时）

1. **能用 a11y 就用 a11y**：`iphone_list_elements` 给出的 `@(x,y)` 才是真坐标。截图预览会被缩放（预览 420 宽 / 实际 375 点），照预览目测点击几乎必错。
2. 捷径编辑器里多数动作卡片**可以**被 a11y 读到（`Button "条件" id="conditionalSubject"`、`Button "textInput" value="a"`…），只有极少数时刻退化成只剩底部工具条——那时再退回截图 + 坐标。
3. 中文键盘的删除键是 `Key "delete" @(349,593)`；旧坐标 `(325,522)` 会打进一串 `l`，把捷径名搞成 `运行快捷指令llllll…`。
4. 提示类弹窗（授权、模态）会**挡住后续所有点击**，每次动作后先看一张截图。

## 4. 四个常用批处理脚本

| 脚本 | 用途 | 用法 |
| --- | --- | --- |
| `ic_del.py` | 批量删捷径 | `python3 ~/ic_del.py 捷径1 捷径2 …`（自动长按 → 删除 → 确认，可滚动查找） |
| `ic_ren.py` | 按名单改名 | `long_press → 重新命名 → 字段 → 清空 → 输入 → 完成` |
| `plan_set.py` | 给服务端写线路清单 | 读 `plans.json` 后 double-URL-encode 打到 `/phone/plans?data=` |
| `ic_seq.py` | 一个会话内顺序执行多工具 | 适合「点开 → 读 → 点选 → 返回」这类连续动作 |

## 5. 与 AI agent 的接法

- CLI 侧：`ssh mac 'python3 ~/ic_call.py …'` 就能被任何 agent 当普通命令用。
- MCP 侧：把 `iphone-control mcp` 直接注册成 MCP server，工具名与上表一致。
- 注意：**同一个守护进程同一时间只服务一个动作流**，两个 agent 并行点按会互相打断——本项目建议「谁持有手机谁操作」。
