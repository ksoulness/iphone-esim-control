# 04 · 服务端：队列、状态与页面

服务端只做四件事：**收指令 → 发门铃 → 记状态 → 报结果**。它不碰手机，也不依赖本项目代码，你完全可以用任意语言重写。

## 1. 端点契约（占位符全部大写）

| 方法 | 路径 | 鉴权 | 作用 |
| --- | --- | --- | --- |
| GET | `/phone/cmd?action=toggle\|default\|status&plan=<卡>&on=1` | `ctl` 口令 / `x-phone-ctl` 头 | 入队一条指令并发门铃 |
| GET | `/phone/state` | 同 | 返回 `plans / queue / history / last / active` |
| GET | `/phone/plans?data=<urlenc json>` | 同 | 整体替换线路清单（`name/alias/number/role`） |
| GET | `/p/<token>/phone/pull[?act=on\|off\|default\|status][&fmt=text]` | token 在路径里 | 手机拉指令（`fmt=text` 返回 `action|plan|on|id|role`） |
| GET | `/p/<token>/phone/report?id=&ok=&detail=&act=&plan=&plans=` | token | 手机回报结果（也用于回报 `status` 与线路清单） |
| GET | `/p/<token>/phone/otp?code=&from=&text=` | token | 验证码入库（可选功能，默认不在页面展示，只推飞书） |

公网无口令访问 `/phone/*` 一律 403；本机 `127.0.0.1` 免口令（反代到页面时用）。

## 2. 线路清单里的 `role`

```json
{"name":"CARD_A","alias":"CARD_A","number":"+44 7700 900001","role":"switch"}
{"name":"US","alias":"US","number":"+1 (555) 010-0001","role":"always_on"}
{"name":"作为“🇸🇬 DATA_A 流量”使用","alias":"DATA_A","number":"","role":"data_only"}
```

- `switch`：可切换，页面上出「换成这张」；
- `always_on`：常开卡，一直占一个槽，不参与切换；
- `data_only`：纯流量卡，不参与切换。
- `name` **必须与手机上显示的线路名完全一致**，否则「查找蜂窝号码」匹配不到（手机上叫 `cte`、清单里写 `CARD_Axcel` 就会永远切换失败）。

## 3. 状态字段

| 字段 | 含义 | 由谁写 |
| --- | --- | --- |
| `queue[]` | 待执行指令（`pending` / `taken`） | `/phone/cmd` 入队 |
| `history[]` | 最近结果（含 `state`、`result`、`done`） | 手机 `report` |
| `last` | **当前在用的那条卡名** | 切卡成功 / toggle 开启成功时写；**`act=status` 回报也会反推**（见下） |
| `active[]` | 手机报告的**活跃线路集合**（通常 2 条：常开 + 当前） | `act=status` 回报时写 |

`last` 与 `active` 必须落盘（`phone-state.json`），**重启不丢**。队列与状态是同一份 JSON，读改写要加锁。

**`status` 回报要反推 `last`**（否则手动切卡后页面永远显示旧卡）：手机报回 `detail=CARD_A,US` 时，遍历 `plans`，挑第一张「`role` 不是 `always_on` / `data_only`、且名字出现在回报里」的卡写进 `last`，名字变了就打一行日志（示例：`[phone] status sync phone_last: CARD_B -> CARD_A`）。

- 只在回报里出现常开卡（例如两张切换卡都被关掉）时，**保持 `last` 不变**，不要清空；
- 这条反推让「用户在手机设置里手动切卡 → 页面点一次『向手机查询当前线路』」也能把高亮纠正回来。

## 4. 页面口径（和用户对齐过的，别再加回去）

`/phone`（「手机号码」标签）只有：

1. 顶部说明 + 「刷新」；
2. **「向手机查询当前线路」按钮 + `当前挂卡：<常开卡> + <last>`**；
3. 每张 `switch` 卡一个「**换成这张**」；当前那张显示 `● 当前` + 绿边框 + 「就是这张，不用再切」；
4. 常开卡 / 流量卡只出灰字说明；
5. 折叠区（`<details>`）：线路清单 JSON 编辑、待执行指令、最近结果。

**不要再加「开启 / 关闭 / 设为默认」按钮**——语义上不存在单独开启，捷径干的就是「关其它 + 开目标」。

## 5. 页面健壮性（踩过的坑）

- 状态接口会经「主队列转发」落到真正持有队列的那台机器，跨机耗时 1.6–3.6 s；不加重试会一直停在「加载中…」。做法：失败自动重试 2 次（间隔 1.2 s），全失败才显示「读取失败 + 重试」。
- 主队列不可达时要**退回本机状态**，不要直接 502（否则整块页面空白）。
- 多标签共用一个页面骨架时，**每个 `pane-x` 都必须带 `display:none`**，且 `tab()` 必须无条件调用一次；漏一个，所有标签看起来都一样。
