# 08 · 运维与排障

## 1. 重启顺序（改完服务端代码后）

```bash
# 1) 语法检查（Python 服务端）
python3 -m py_compile /path/to/universal-push-proxy.py
# 2) 重启
sudo systemctl restart push-translator        # NAS 侧（页面 + 队列代理）
sudo systemctl restart push-leg-hw            # 云主机侧（主队列，若分两台）
# 3) 冒烟三连
systemctl is-active push-translator
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:<port>/          # 期望 200
curl -s 'http://127.0.0.1:<port>/phone/state' | head -c 200                # 期望含 plans
```

⚠️ **重启后第一次 curl 可能拿到 `000`**：那是进程还没 bind 完，`sleep 3` 再测；不要据此判定代码坏了。

## 2. 手机侧排障

```bash
ssh mac 'export PATH=$HOME/.cargo/bin:$PATH; iphone-control status; iphone-control doctor'
ssh mac 'pkill -f "iphone-control daemon"; nohup iphone-control daemon > /tmp/ic_daemon.log 2>&1 &'
ssh mac 'tail -50 /tmp/ic_daemon.log'
```

## 3. 故障对照表

| 现象 | 根因 | 修法 |
| --- | --- | --- |
| `doctor`：`USB 上没有 iPhone/iPad` | 线只充电 / 手机锁死 / usbmuxd 抢占用 | 换数据线、解锁、`pkill -f "goios/ios"` |
| `ImageMountFailed ... Developer mode is not enabled` | 开发者模式被关（OTA/抹机后常见） | 设置 → 隐私与安全性 → 开发者模式 → 重启 |
| `cryptexd ... /System/Developer [17: File exists]` | DDI 已被 go-ios 挂过 | `~/goios/ios image unmount` → 重启 daemon |
| 工具调用 `timed out draining in-flight responses` | MCP 会话卡死 | 重启 daemon |
| 自动化收到短信但没动作 | 触发器还是「发件人 是 []」 | 改条件为「信息 包含 …」 |
| 自动化动作跑一半停 | 系统模态挡屏（默认设置已更改 / 允许连接） | 手机上点掉；此后不要再用「设定默认号码」 |
| 第二次切卡无效 | 上一条留下模态 | 同上 |
| 手机名与清单不一致 → 切卡失败 | `name` 不匹配 | 清单里改 `name` 为手机上的真实线路名 |
| 页面「加载中…」不动 | 主队列跨机慢 / 不可达 | 代码需内置重试 + 回退本机状态 |
| 所有标签页看起来一样 | 某些 `pane-x` 漏了 `display:none`，`tab()` 未被无条件调用 | 补齐 `display:none`，`tab()` 一定调一次 |

## 4. 日志在哪

| 侧 | 位置 |
| --- | --- |
| 服务端（NAS） | `journalctl -u push-translator -n 100 --no-pager`；业务日志 `proxy-<port>.log`（可能含二进制，先 `strings`） |
| 服务端（云主机） | `journalctl -u push-leg-hw -n 200 --no-pager`；`grep '\[phone\]'` 过滤 |
| 云主机 nginx | `/var/log/nginx/<site>-access.log`（手机捷径的 UA 是 `BackgroundShortcutRunner`） |
| 手机控制 | Mac `/tmp/ic_daemon.log` |

## 5. 备份约定

改服务端前永远先备份，命名带语义和时间：

```bash
cp universal-push-proxy.py universal-push-proxy.py.bak-<改动名>-$(date +%Y%m%d-%H%M)
```

本项目涉及过的 marker（便于 grep 回溯）：`PHONE_ACTFILTER` / `PHONE_FEISHU` / `PHONE_REPORT_ANY` / `PHONE_REPORT_FUZZY` / `PHONE_MSG2` / `PHONE_MSG3` / `PHONE_ACTIVE` / `PHONE_ACTIVE3` / `PHONE_ACTIVE4` / `PHONE_MASTER_FALLBACK` / `PHONE_MOVEBLOCK` / `PANE_DEFAULT` / `PHONE_MERGE` / `PHONE_DROPPLANS` / `PHONE_DROPOTPUI` / `NSWAP_RETRY`。

## 6. 健康自检（建议每天一次）

```bash
# 1) 手机在线
ssh mac 'export PATH=$HOME/.cargo/bin:$PATH; iphone-control status | head -3'
# 2) 服务端活着
curl -s -o /dev/null -w '%{http_code}\n' http://127.0.0.1:<port>/
# 3) 状态记得住
curl -s 'http://127.0.0.1:<port>/phone/state' | grep -o '"last": *"[^"]*"'
# 4) 全链路（会真的切一次卡）
curl -s 'http://127.0.0.1:<port>/phone/cmd?action=status&ctl=<口令>'
```
