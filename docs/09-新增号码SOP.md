# 09 · 新增号码 SOP（以后加卡照这个做）

假设要新加一张卡，手机上叫 `JP`。

## 步骤

1. **手机侧确认名字**：设置 → 蜂窝网络，看这条线路显示的确切名称（例如 `JP`；如果是 `作为“🇯🇵”使用` 就得按这个字符串来）。
2. **服务端加清单**：`/phone/plans?data=<urlenc JSON>`，追加
   `{"name":"JP","alias":"JP","number":"+81 ...","role":"switch"}`
   （`role` 取 `switch` 可切换 / `always_on` 常驻 / `data_only` 纯流量）。
3. **按 `切换hk` 复制一条捷径**：长按 → 复制 → 改名 `切换jp` → 改 4 处：
   - 关闭列表里去掉 JP、保留其它三条；
   - 「打开」改成 JP；
   - 回报 URL 里两处 `detail=` / `plan=` 改成 `jp`。
   （本项目已验证的复制路径：长按卡片 → 菜单「复制」(141,529) → 改名。）
4. **复制一条自动化**：长按 `切换hk自动` → 「编辑快捷指令」→ 把触发词改成 `#phone on JP`（**前缀要能匹配门铃正文**）→ 把「运行」的目标改成 `切换jp` → 返回保存。
   > 新模型的自动化卡片菜单里**没有「复制」**，只能在编辑器里改；也可以新建一条（见 [03](03-在手机上写捷径与自动化.md) 第 5 节的点击链）。
5. **页面验证**：`/phone` 刷新应出现 JP 那张卡与「换成这张」；点它，等 7–12 秒看飞书 ✅。
6. **文档同步**：把新卡记到 `docs/07-远程切卡实战.md` 的现场条件里。

## 常见错误

| 错误 | 后果 |
| --- | --- |
| `name` 写成别名（手机叫 `CARD_C`，清单写 `PH`） | 「查找蜂窝号码」匹配不到，切卡永远失败 |
| 捷径里忘了改「打开」目标 | 会把另一张卡打开、目标没动 |
| 触发词写成 `#phone default JP` 而门铃发的是 `#phone on JP` | 自动化不触发 |
| 忘了给新自动化做一次性授权 | 第一次触发弹窗，若被挡住则静默失败 |
| 忘了同步 `plans` 导致页面没有这张卡 | 页面点不到，但门铃可以手动测 |

## 删除一张卡

1. 删 `切换X自动`、`切换X` 两条捷径；
2. 从 `plans` 里去掉该条（`/phone/plans` 整体替换）；
3. 检查其它三条切卡捷径的「关闭」列表里是否还引用它——**必须一起去掉**，否则每次切卡都会去关一条已不存在的线路（无害但会多一次失败记录）。
