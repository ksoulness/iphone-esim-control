# 10 · 安全与边界

## 1. 这套东西能做什么

- 远程让手机切换蜂窝/eSIM 线路（关其它 + 开目标），并回报当前在用哪张；
- 远程读取手机界面状态（前台 App、元素树、截图）；
- 远程在手机上建/改/删捷径与自动化（通过本项目提供的脚本，需要主机端权限）；
- 把「切换结果 / 线路状态 / 验证码」推到即时通讯（飞书等）。

## 2. 明确不做的事

- **不越狱**、不改系统文件、不装描述文件、不用企业证书；
- **不绕过**锁屏密码、不读其它 App 的私有数据；
- **不做**「设默认线路」这类会留下系统模态的动作（会破坏无人值守）；
- **不在页面展示验证码**（用户选择只在飞书看，减少暴露面）；
- **不把 token / 口令写进文档或日志**：文档里一律 `<TOKEN>` / `<口令>` 占位。

## 3. 凭证清单（部署时你自己生成）

| 凭证 | 用途 | 存放建议 |
| --- | --- | --- |
| `mobile-push-token` | 手机侧 `/p/<token>/…` 路径鉴权 | 服务端 600 权限文件；手机捷径 URL 里含它，注意别外发截图 |
| `ctl` 口令 | 页面/接口入队鉴权 | 同上；页面用 `ctl` 参数或 `x-phone-ctl` 头 |
| 飞书 app_id/secret + 群 chat_id | 推结果 | 放服务端 env 或 `feishu.env`（600） |
| iMessage 网关地址 | 发门铃 | 内网即可，公网就不要开 |

## 4. 暴露面控制

- `/phone/*` 公网必须 403（无口令），只让 `127.0.0.1` 免口令，供页面反代；
- 手机侧 `/p/<token>/…` 走长 token，不要贴到公开聊天里；
- 页面本身若挂在公网，**至少一层认证**（Basic / 反代 auth / 内网 tailnet）。

## 5. 已知风险

| 风险 | 说明 | 缓解 |
| --- | --- | --- |
| token 泄露 | 别人可伪造 `report` 写状态（不能直接控制手机） | 轮换 token，捷径 URL 一起改 |
| 门铃被伪造 | 任何能给这个号发短信的人都能触发切卡 | 触发词加随机前缀，或改用只有自己知道的短语 |
| 手机被手动改过 | `last` 与真实不一致 | 点「向手机查询当前线路」以手机实测为准 |
| 自动化被系统模态挡住 | 无人值守时静默失败 | 不要用「设定默认号码」；看门狗 150 s 报失败 |
