# 通道与触发器矩阵（iOS 27）

> 一句话：**触发手机和搬运数据是两件事**。iOS 27 起「通知」触发器让「任意 App 的推送」也能当触发器，通道选择一下变宽。

## 1. iOS 27 的自动化触发器全集

| 分类 | 触发器 | 无人值守 |
| --- | --- | --- |
| 事件 | 时间、闹钟、睡眠、体能训练、声音识别、**截屏**、**键盘连/断** | ✅ |
| 通讯 | **信息**、**邮件**、**通知（任意 App，本文件重点）** | ✅ |
| 出行 | 到达、离开、CarPlay | ✅ |
| 交易 | Apple Pay 商户匹配 | ✅ |
| 设置 | Wi‑Fi、蓝牙、专注模式、低电量、电池电量、充电、NFC、App 打开/关闭 | ✅ |
| 手动 | 点图标、控制中心、操作按钮、Siri、Spotlight | ❌ 需人 |

**iOS 26 及以前没有「通知」触发器**（那会儿只有信息/邮件）；iOS 27 新增，和老系统写文档时容易搞错。

## 2. 通知触发器怎么配

`快捷指令 → 自动化 → + → 通知`

| 项 | 说明 |
| --- | --- |
| App | 选发通知的 App（Bark / ntfy / Gotify / 飞书 / HA / 自家 App 都行） |
| Add Filter | 最多 3 条，可分别筛 **Title / Subtitle / Message**，大小写不敏感 |
| 运行前询问 | 关掉 → 后台静默执行；**锁屏状态下同样会跑** |

⚠️ 前提：该 App 的通知权限必须开着；通知必须真的送达（勿扰模式会把横幅收进通知中心，是否仍触发**需实测**）。

## 3. 通道 × 触发器对照

| 发送通道 | 能当触发器？ | 配哪个触发器 | 备注 |
| --- | --- | --- | --- |
| iMessage / 短信 | ✅ | 信息（发送者 + 包含 `#phone`） | 现役方案，秒级 |
| Email | ✅ | 邮件（主题/正文） | 抓取模式下 5–15 分钟延迟 |
| **Bark** | ✅（iOS 27+） | **通知**（App=Bark，Filter=Message 含 `#phone`） | 可自定义 body → 能带参数 |
| **ntfy / Gotify** | ✅（iOS 27+） | **通知** | 同上，自建推送最省 |
| **飞书 / Telegram / 企业微信** | ✅（iOS 27+） | **通知**（App=飞书） | 顺手还有群消息留痕 |
| Home Assistant | ✅（iOS 27+） | **通知**（App=HA Companion） | 可反向由 HA 编排 |
| webhook / 自建 API | ❌ 本身不是通知 | 需经上面任一 App 转发 | 或走轮询 |
| 时间轮询 | ✅ | 时间（每 N 分钟） | **零通道依赖兜底**，延迟 ≤N 分钟 |

## 4. 两种组合方式

**A. 推送触发（快）**
```
服务端 → Bark/ntfy/飞书 推送（body 含 "#phone on HK"）→ 通知触发器 → 切卡快捷指令 → report
```

**B. 定时轮询（稳）**
```
手机每 5 分钟 → GET /p/<TOKEN>/phone/pull?fmt=text → 空则忽略 → 有则执行 → report
```
两者可并存：推送优先，轮询兜底；`PHONE_NUDGE_CHANNEL=none` 即纯轮询。

## 5. 参数化指令（通知触发器带来的新能力）

通知的 Title/Subtitle/Message 三段都能被捷径读进变量，所以可以做成**两段协议**：

```
Title:    #phone
Message:  on|off|status|default  <CARD>
```

捷径里「获取通知详情」→ 取值 → 走对应分支。比 iMessage 纯文本更结构化，也不必再占用一个号码。

## 6. 结果回传通道（手机 → 服务端）不受限

捷径「获取 URL 内容」支持 GET/POST/JSON/自定义头，「发送邮件」「发送信息」也在动作库，所以回传可以走：自建 API、飞书 webhook、Bark、ntfy、Gotify、邮件、短信。当前用的是 `report?ok=1&detail=…&act=…&plan=…`。

## 7. 排障优先级

1. 触发器跑没跑：看快捷指令里「最近运行」时间点
2. 跑没跑通：`GET /phone/state` 的 `queue` 是否清空、`history` 是否有条目
3. 通知有没有到：锁屏通知中心里能看到吗
4. 权限：App 的通知权限 + 捷径的「运行前询问」是否已关 + 首次的「允许连接 <域名>」是否点过
